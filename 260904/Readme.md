- Cách lệnh sử dụng git cơ bản : 
    - Đăng nhập thông tin tài khoản git trên hệ thống máy tính : 
    ```bash
        git config --global user.email "vua75644@gmail.com"
        git config --global user.name "Pham-Ba-Vuong"
    ```
    - Các lệnh sử dụng cơ bản 
        - Lưu commit thay đổi và push lên nhánh main 
        ```bash
            git add . 
            git commit -m "ghi hchut commit " 
            git push origin main  
        ```
        - Kiểm tra trạng thái repo xem có những thay đổi gì chưa commit : 
            ```bash
                git status 
            ```
        - Kiểm tra nhánh branch đang đứng , chính sửa hiện tại :
        ```bash
            git branch 
        ```
        - Liệt kê toàn bộ nhánh đang có trên repo git 
        ```bash
            git branch -a
        ```
